# Bolajonlar — O‘ynab o‘rganamiz! 🧶

Bolalar uchun **to‘qilgan ip / crochet / yarn** uslubidagi, internetisiz ishlaydigan ta’limiy PWA web-ilova.

## Ishga tushirish
1. ZIP faylni oching.
2. Ichidagi `bolajonlar` papkasidagi barcha fayllarni GitHub repository root qismiga yuklang.
3. GitHub Pages-ni yoqing.
4. HTTPS orqali ochilgan sahifada PWA o‘rnatish funksiyasi ishlaydi.

## Xususiyatlar
- Harflar, sonlar, ranglar, shakllar, tana a’zolari, vaqt, hayvonlar, mevalar, tabiat va transport.
- Har bir elementda **Oldingisi / Keyingisi** navigatsiyasi.
- `SpeechSynthesis API` orqali ovozli o‘qish.
- 10 savollik quiz va yumshoq to‘g‘ri/xato animatsiyasi.
- LocalStorage orqali eng yaxshi 10 ta natijani saqlash.
- Service Worker orqali offline app-shell cache.
- Tashqi CDN, Google Fonts yoki tashqi rasm URL ishlatilmaydi.
- Barcha asosiy ikonlar lokal SVG formatida.

## Eslatma
Ovoz sintezi brauzer va qurilmadagi mavjud ovozlarga bog‘liq. Ilova internetga bog‘lanmaydi; agar qurilmada `uz-UZ` ovozi bo‘lmasa, tizim mavjud yaqin ovozdan foydalanishi mumkin.
